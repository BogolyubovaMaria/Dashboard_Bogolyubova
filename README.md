# Dashboard_Bogolyubova
Тема: Панель читателя. Собрана из карточек-виджетов: секундомер чтения, график за неделю, поиск книг, цель на год,
статус сервисов, «Книга дня». Через меню сверху можно добавить список дел, погоду и курсы валют.
Любую карточку можно свернуть или удалить — всё сохраняется после перезагрузки.

Источники API:
Open-Meteo — погода (температура, ветер, влажность).
Frankfurter — курсы валют (EUR к USD, GBP, JPY, CHF).
Дополнительно используется Open Library для поиска книг и «Книги дня».
